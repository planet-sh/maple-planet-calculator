💾 입력값은 현재 브라우저에 자동 저장되며 다음 방문 시 자동 복원됩니다. 서버로 전송되지 않습니다.
간편 계산기 · 빠른 매물 비교용입니다. 깡 주스탯 5 = 공1, 주스탯 1.5% = 공1의 러프 환산을 사용합니다.

1. 캐릭터 / 장비

직업 선택 시 기본값이 자동 입력됩니다. 다른 크확 효과가 있다면 직접 수정할 수 있습니다.
찐샾 적용 수치는 직업별 자동 반영
무기 + 공격력이 붙은 장비의 공격력을 모두 합산해 입력하세요.
10/21 기준: 무기 + 장갑 + 얼굴장식 + 카혼목 + 염주 + 월묘 + 훈장
예시) 무기 99 + 장갑 13 + 카혼목 5 + 월묘 5 + 훈장 3 = 125
※ 잠재능력의 깡공(+12/+14/+16 등)은 제외합니다. 무기 잠재에서 자동 계산됩니다.
성벽 사냥 시 적용할 공격력 버프를 선택하세요. 버프 공격력은 공% 적용 대상에서 제외됩니다.

2. 공1당 스공 효율 측정

공격력 수치가 다른 장비 두 개를 같은 조건에서 각각 착용하고 MIN / MAX 스공을 입력해주세요.
예) 월묘 공2 견장 ↔ 월묘 공3 견장
※ 테스트 장비 외 다른 장비·버프·스킬·펫·칭호 조건은 동일해야 합니다.

측정 ①

측정 ②

측정된 공1당 스공 효율MIN - / MAX -두 장비의 공격력과 MIN / MAX 스공을 입력하면 자동 계산됩니다.

3. 주스탯 1당 스공 효율 측정

깡 주스탯만 알고 있는 장비/칭호를 착용 전후로 비교합니다. 올스탯 장비를 사용해도 되며, 이 버전에서는 부스탯 상승으로 인한 스공 변화는 무시합니다.
예) 올스탯 +2 공용 칭호 → 테스트 장비 주스탯 증가량에 2 입력
※ A+B는 검증용입니다. 주스탯 1의 효율은 장비에 적힌 원래 주스탯 증가량으로 계산합니다.

미착용

착용

측정된 주스탯 1당 스공 효율MIN - / MAX -착용 전후 스공과 장비의 깡 주스탯을 입력해주세요.

4. 주스탯 1%당 스공 효율 측정

깡 주스탯 + 주스탯%가 함께 붙은 장비를 착용 전후로 비교합니다. 전체 스공 상승분에서 위에서 측정한 깡 주스탯 효과를 먼저 제외한 뒤, 남은 상승분을 주스탯%로 나눕니다.
예) STR +7 / STR +14% 장비 → 깡 주스탯 7, 주스탯% 14
※ 3번과 4번 측정도 가능한 한 같은 장비·버프·스킬 조건을 유지해주세요.

미착용

착용

측정된 주스탯 1%당 스공 효율MIN - / MAX -3번 주스탯1 측정 후, 잠재 장비 착용 전후 값을 입력해주세요.

3. 현재 무기 / 비교 매물

총데미지는 각 무기를 착용했을 때의 최종 스탯창 총데미지를 입력하세요. 기본은 현재 무기 + 매물 A이며, 필요할 때 B / C를 추가해 최대 3개 매물을 비교할 수 있습니다.
※ 무기 순수 공격력을 입력하지 않은 매물은 계산 결과에서 제외됩니다. 가격은 억 메소 단위이며 현재 무기는 가격을 입력하지 않습니다.

계산 전제
공격력% 적용 베이스 = 후보 무기 적용 후 장비 순수공 합 + 해당 무기의 잠재 깡공. 혼테일/핑크빈/요괴대사 등 버프 공격력은 공% 적용 대상에서 제외하고 최종 공격력에 더합니다. 간편 계산은 깡 주스탯 5 = 공1, 주스탯 1.5% = 공1로 러프 환산합니다. 주/올스탯의 부스탯 가치는 포함하지 않습니다. 본 도구는 사냥용 무기 잠재의 상대 효율 비교용입니다.
