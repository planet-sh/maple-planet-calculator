4. 직거래 · 내부구매 정산

직거래 금액은 단순히 6%를 차감하지 않고, 판매자가 경매장 판매 시와 동일한 금액을 최종 수령하도록 역산합니다.
① 손익분기 직거래가경매장 실수령액과 직거래 실수령액 일치
② 지급 방식공대원에게 직접 택배 / 대표자에게 교환
③ 지분 정산N빵 또는 차등 지분 + 택배비 반영

① 판매자 실수령 동일 직거래가

경매장 판매 시 실수령-
동일 실수령 직거래 교환금액-
최저가를 입력하면 자동으로 손익분기 직거래 금액을 계산합니다.

② 지급 방식

구매자가 각 공대원에게 직접 택배를 보냅니다. 각 사람의 지분 금액에서 택배 8%를 역산해 실제 송금액 + 택배 수수료 = 해당 사람의 지분 비용이 되도록 계산합니다.
구매자는 대표자에게 기준 총액을 교환으로 일괄 지급합니다. 대표자 본인 몫에는 택배 수수료가 없고, 나머지 공대원에게 보내는 금액에만 택배 수수료를 역산합니다.

③ N빵 · 차등 지분

대표자 교환 방식에서는 차등 인원을 대표자를 제외한 나머지 공대원 중에서 계산합니다. 대표자 분배율은 위 항목에서 별도로 지정합니다.
직거래 교환금액-
판매자 최종 실수령-
경매장 최저가 대비 구매자 절감-
총 택배 수수료-
총 지분-
구분인원분배율1인 지분비용1인 실제 수령
